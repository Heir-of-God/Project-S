Welcome! Project S is my personal archive of Python solutions to **LeetCode**, **HackerRank** and **Codeforces** problems. I'm a Software Engineering student, and this is where I practise algorithms and data structures and keep track of everything I've solved. It is a learning project first: my solutions may be ineffective, complex or confusing, since I, like many others, am constantly learning💫. I try to keep them readable (most use type hints) rather than clever.

## 🗂️ Repository Layout

```
Project-S
├── Leetcode
│   ├── Dailys          <DD.MM.YYYY>.py
│   ├── Contests        <Weekly|Biweekly N>/<problem #>.py
│   ├── Study plans     <plan name>/<problem #>.py   (TopInterview150)
│   └── Others          <problem #>.py
├── HackerRank
│   └── PreparationKits <kit name>/Week<N>/<#> <problem_name>.py   (3months)
└── Codeforces
    ├── Contests        <contest name>/<problem letter>.py
    ├── Problemsets     <list name>/link.txt   (link to the source of the problem list)
    └── Others          <contest id + letter> <problem_name>.py   (e.g. 1790A polycarp_and_the_day_of_pi.py)
```

P.S. A file for one LeetCode solution may contain several "Solution" classes (several approaches found) or a re-solution if, for example, the daily task had already appeared before📆.

## 📥 How to Use

Each file is a standalone solution, so there is nothing to install:

1. **First of all, give a star to this repo if you find it interesting or useful**⭐\
    **Thanks ❤️**

2. **Clone the repository** (you need git set up):
   ```bash
   git clone https://github.com/Heir-of-God/Project-S.git
   ```

3. **Pick a solution and run it**. HackerRank and Codeforces files are plain scripts that read from standard input (you need Python 3 installed and added to PATH):
   ```bash
   python "HackerRank/PreparationKits/3months/Week1/1 plus_minus.py"
   ```

4. **LeetCode files** contain a `class Solution` (the format LeetCode expects). Copy the class into the LeetCode editor, or import it in your own script. Some files rely on LeetCode's own helpers (e.g. `TreeNode`, `Optional`), which are shown in comments at the top. LeetCode files are named by problem number (or by date for Dailys), so use that to look the task up on the site.
